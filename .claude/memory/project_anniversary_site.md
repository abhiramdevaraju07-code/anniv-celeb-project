User is building a Netflix-themed static website to celebrate their 3-month relationship anniversary.

**Why:** Romantic gift for their partner, inspired by a viral TikTok/Instagram reel (anayaawarr).

**Structure built at:** `/Users/dabhiram/personal/anniv-celeb-project/`

**Pages:**
- `index.html` — Netflix "N" logo intro animation
- `profiles.html` — "Who's Watching?" with 3 month milestones
- `browse.html` — Full Netflix UI with hero + gallery rows
- `player.html` — Photo slideshow with Netflix player controls → auto-advances to credits
- `credits.html` — Rolling movie-style credits

**Personalization file:** `js/config.js` — all names, photos, messages in one place.

**Photos:** User will add own photos gradually. Placeholder gradients used until then.
- `images/hero.jpg` — hero photo on browse page
- `images/profiles/month-1.jpg`, `month-2.jpg`, `month-3.jpg` — profile milestones
- `images/gallery/1.jpg` through `10.jpg` — gallery + slideshow photos

**Hosting:** GitHub Pages (push to main, enable Pages in Settings)

**How to apply:** When user shares photos or wants to change names/messages, update `js/config.js` and the images folder. All personalization is centralized there.
